## Course objectives and outcomes

The course introduces Android and iOS operating systems, application components and layouts, database connectivity including real-time databases, and development of an Android/iOS application.

| Outcome | Expected capability |
| --- | --- |
| CO1 | Design user interfaces using Android Studio and Flutter. |
| CO2 | Implement file handling using text and images. |
| CO3 | Implement database connectivity and location tracking. |
| CO4 | Develop a full-fledged Android/iOS application. |

### Laboratory rules

- There are 10 practicals, each assessed out of 20. Their average provides the lab component out of 20.
- Peer discussion is allowed, but each student must submit original work. Very similar submissions receive zero marks.
- Evaluation considers timely completion of the lab file, understanding, originality, involvement, regularity and discipline.
- **Late submissions carry a 30% penalty.**
- One lab is assigned to Android Studio installation and emulator configuration. Project interests and research trends may also be discussed; presentations may be included.
- Viva evaluates concepts learned during the course.

### Mini-project rules

- Faculty forms groups of **2–3 students**.
- Groups work on different projects after topic approval.
- Implement the project using concepts learned in the course.
- Assessment considers implementation technique, results, originality and understanding.
- The policy does not specify a mandatory project domain or an exact required feature list.

## GenAI usage and academic integrity

The policy explicitly includes these GenAI learning activities:

- Before class, explore current mobile development trends, core components and technologies with examples, and differences between iOS and Android development processes.
- In class, use generative AI to explore additional functionality for assigned open-ended problems.

All assessed work must still be original. Copying in any form is unacceptable and may lead to disciplinary action and an impact on the corresponding assessment component. Plagiarism detection software may be used. These learning activities do not state unrestricted permission to submit generated work as one's own.
